# Rohan Kumar Sah, Portfolio

Personal portfolio of Rohan Kumar Sah: full stack developer and UI/UX designer based in Vadodara, Gujarat.

Single-page site (plain HTML, CSS and a little JavaScript, no build step). It covers projects, experience, a dated milestones timeline, a certificates wall with filters and a lightbox, skills, and contact details. Light and dark themes are supported.

## Run locally

Open `index.html` in a browser.

## Folders

- `index.html`: the whole site
- `img/`: web-sized images used by the site
- `originals/`: original certificate files

## Publish with GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root.
